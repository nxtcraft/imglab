How to Compress an Image

  1. Open ImageCraft and drop your image (JPG, PNG, WebP, GIF).
  2. Select the Compress tab.
  3. Drag the quality slider — 80–85% is the sweet spot for web use.
  4. Compare the before/after file size shown in the preview.
  5. Click Download to save the compressed image.

How to Resize an Image

  1. Drop your image and select the Resize tab.
  2. Enter a target width or height. Enable Lock Aspect Ratio to avoid distortion.
  3. Or enter a percentage (e.g. 50% to halve the dimensions).
  4. Click Download. The original file is not changed.

Privacy: Why No Upload?

ImageCraft uses the browser's built-in Canvas API and File API to process images locally on your device. This means your photos are never sent to any server — they stay completely private. This is especially important for ID documents, medical images, or any sensitive photos.

Frequently Asked Questions

Does ImageCraft upload my photos?

No. All processing is done locally in your browser. Images never leave your device. No server, no account, no storage.

What is the best image format for websites?

WebP gives the smallest file size with good quality and supports transparency. Use it for web when possible. JPG for photos, PNG for graphics with sharp edges or transparency.

What quality setting should I use?

80–85% for web images is the best balance — the file is 2–5× smaller than 100% and most people can't tell the difference. Use 60–70% for thumbnails, 95%+ for print.
